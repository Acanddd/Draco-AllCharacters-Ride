## Install / 安装

Requires a working game mod resource loading setup. Close the game and launcher, remove the previous Draco mod through your mod manager or remove only its owned files, then extract the ZIP and place the `Draco_AllCharacters_Ride_v1.5.2` folder under `HT/Content/Paks/~mods`. Keep all three `.pak`, `.utoc` and `.ucas` files together. Do not load duplicate Draco versions.

需要已配置好的游戏 MOD 资源加载环境。退出游戏和启动器，通过管理器移除旧版 Draco，或仅移除其所属文件；解压 ZIP，将 `Draco_AllCharacters_Ride_v1.5.2` 文件夹放入 `HT/Content/Paks/~mods`。保留配套的 `.pak`、`.utoc`、`.ucas` 三个文件，不要同时加载多个 Draco 版本。

To uninstall, remove this mod's folder or remove the mod through your manager. Keep unrelated mods and shared loaders.
卸载时移除本 MOD 文件夹，或通过管理器移除；保留其他 MOD 和共享加载器。
